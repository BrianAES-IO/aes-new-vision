Why AESURUS OS

Everything you need.
Already set up.

Older laptops slow down, stop getting security updates and end up in a drawer. AESURUS OS gives them a second life with a clean desktop and protection that's on by default.

Encrypted from day one

The installer encrypts the whole disk on every install, and doesn't let you skip it. If a laptop is lost or stolen, your data stays locked. A 48-digit recovery key means you're never locked out, and you can make a new one at any time.

Protected while you work

The firewall and AppArmor are on, and security updates install automatically.

Private DNS

DNS lookups are encrypted, so public Wi-Fi can't see where you browse. Wi-Fi sign-in pages still work with one click.

Smart Ops

It tunes itself to your hardware at every startup and warns you before memory runs low. It never closes your work.

Data Saver

New Wi-Fi networks are treated as metered, large downloads wait, and you set a data budget.

AES-Office included

AES Write, AES Calc and AES Present open and save Word, Excel and PowerPoint files by default. Microsoft 365 web apps are one click away.

Make it yours

You can change the theme, accent colour, fonts, wallpaper, icons and panel layout. Our design is a starting point, not a locked box.

Under the hood

Built on a proven foundation

AESURUS OS is built on Debian, one of the most stable and trusted Linux systems in the world, with the KDE Plasma desktop. We add the security defaults, tuning, design and tools that make it ready for everyday use.

If you're online during setup, Chrome and Edge are installed automatically. Firefox is always included as a fallback.

BaseDebian 13 “Trixie”
DesktopKDE Plasma 6 on Wayland
Hardware64-bit Intel or AMD, 4 GB RAM or more
BootBIOS and UEFI, Secure Boot supported
DiskFull-disk encryption + recovery key
NetworkFirewall, AppArmor, DNS-over-TLS
UpdatesAutomatic security updates; data-aware on metered connections
